# Largest-client PTY sizing

Accepted: one PTY-backed Tab has one shared row/column geometry for every Client attached to its Session. The Server chooses the maximum usable pane rows and columns independently across attached Clients, recomputes on attach/detach/resize, and retains the last geometry while no Clients are attached. Each Client renders the shared terminal state in its own viewport, clipping when smaller or leaving unused cells when larger; it cannot cause independent shell reflow or glyph scaling. Client-only overlays such as the Workspace Drawer never contribute to the PTY dimensions.

# Retained client-local Lua UI tree

Accepted: configurable UI Elements are created while loading the Client's Lua configuration and retained as a Client-local tree of nested Layouts and display primitives; no Lua render callback runs per frame in version one. Lua owns content and interaction semantics and changes visible values through typed handle mutations, which mark affected UI dirty and coalesce redraw requests. Layouts begin with nested Rows and Columns whose children are fixed-size, content-sized, or equally share remaining space; drawers overlay the terminal at the left or right, do not resize shared PTYs, and clip overflow. Focused elements use direct local bindings before the main dispatcher, except that the global leader mode gives the main dispatcher exclusive input; unmatched focused-element keys may fall through to main bindings but never to the PTY, and no-op callbacks consume bindings while nil removes them. The built-in Workspace Drawer is removed rather than migrated; custom Lua UI can provide equivalent behavior. Cached cell buffers are deferred beyond version one.
